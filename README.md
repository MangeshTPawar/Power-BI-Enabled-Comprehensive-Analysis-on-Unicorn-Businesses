# Power-BI-Enabled-Comprehensive-Analysis-on-Unicorn-Businesses


## 📌 Overview
This project delivers an **interactive Power BI dashboard** that analyzes global unicorn companies.  
It highlights **trends in valuations, funding, industry distribution, geographic spread, and investor involvement**, providing a clear view of the unicorn ecosystem.

---

## 📂 Dataset Summary
- **Total Companies:** 1072  
- **Continents Covered:** 6  
- **Countries:** 46  
- **Cities:** 257  
- **Industries:** 15  
- **Total Funding:** $591.82 Billion  
- **Total Valuation:** $3711 Billion  
- **Average Years to Unicorn:** 7
